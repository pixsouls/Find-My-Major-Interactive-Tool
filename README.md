# Find-My-Major-Interactive-Tool

A RIASEC / Holland Code career assessment for MSU Denver. Take an adaptive quiz,
get a Holland code, see matching careers and the MSU majors behind them.

- `Frontend/` — React + TypeScript + Vite
- `Backend/` — Node + Express

**Start here:** [HANDOFF.md](HANDOFF.md) — architecture, the read-only data
rule, deployment, and what's in progress.
Frontend details: [Frontend/frontend_docs.md](Frontend/frontend_docs.md).
